## Start With the Default Profile

The **Potluck profile** is the primary troubleshooting baseline.

If you encounter a problem:

1. Switch to the Potluck profile.
2. Do not add, remove, update, enable, or disable anything.
3. Reproduce the problem.

If the issue occurs on the Potluck profile, the issue might be with the Mod List.

If it only occurs on your customized profile, the problem is likely related to your changes.

---

## Check the Basics

Before troubleshooting individual mods, confirm:

- Stardew Valley is the version currently supported by Potluck.
- Potluck was installed successfully through Wabbajack.
- You are using the **Mod Organizer 2 provided with Potluck**.
- You did not manually install another copy of SMAPI.
- Vortex is not deploying Stardew Valley mods.
- No old mods remain in the game directory or AppData Mods folders.
- You are launching Stardew Valley through Potluck's configured MO2 executable.

If your base installation is not clean, fix that before troubleshooting individual mods.

## Custom Profiles

If the problem only occurs on your custom profile, consider what changed.

Check any mods you:

- Added
- Removed
- Updated
- Enabled
- Disabled
- Reconfigured

Read the MO2 Notes for affected mods and verify their requirements and known incompatibilities.

---

## SMAPI Log

The **SMAPI log** is usually the most useful diagnostic information for Stardew Valley mod problems.

When requesting support, provide the complete SMAPI log rather than only a screenshot of an error.

Screenshots can show the symptom.

**The log helps show the cause.**

---

## Compatibility Checker

Run the **Potluck Compatibility Checker** from Mod Organizer 2.

Resolve any reported missing requirements, incompatible combinations, or other known configuration problems before continuing troubleshooting.

A clean Compatibility Checker result does not guarantee that every possible mod combination is compatible.

---

## When Asking for Help

Please include:

- What happened
- What you expected to happen
- Whether it happens on the Default profile
- Your SMAPI log
- Any mods you added, removed, updated, enabled, or disabled
- Relevant screenshots when useful

If the problem only occurs with off-list mods or a customized profile, identify those changes when asking for help.

*"It doesn't work"* is unfortunately not a diagnostic tool.
