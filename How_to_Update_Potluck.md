# 🍲 How to Update Potluck

Potluck updates are installed through **Wabbajack**, the same way you originally installed the list.

Always read the revision notes before updating.

## Before Updating

Before installing a new Potluck revision:

1. Read the revision notes.
2. Check whether the update is safe for an existing save.
3. Back up your saves.
4. Close Stardew Valley and Mod Organizer 2.

Do not assume every Potluck revision is save-safe.

---

## Back Up Your Saves

Back up any Stardew Valley saves you care about before updating.

This gives you a way to return to your previous setup if an updated, added, or removed mod causes problems with an existing playthrough.

---

## Protect Your Customizations

The supplied **Potluck profile** may be changed by an update.

If you customize the mod list, use your own MO2 Profile rather than modifying the Potluck Profile.

Before updating, make note of any personal changes or off-list mods you have added.

---

## Update Through Wabbajack

1. Launch **Wabbajack**.
2. Select the newest Potluck release.
3. Use the **same Potluck installation folder** as your existing installation.
4. Use your existing download folder.
5. Start the installation.
6. Allow Wabbajack to update the list.

Wabbajack will reuse files it already has whenever possible and download files that have changed.

It's normal if it asks you to delete hundreds or thousands of files during this update process. Hit ok.

---

## After Updating

Launch the included **Mod Organizer 2** and review the updated Default profile.

If you use a customized profile, check that your selections and off-list mods still make sense with the new revision.

Run the **Potluck Compatibility Checker** after making or restoring customization changes.

---

## Save Compatibility

Whether an update is safe for an existing save depends on what changed.

The release notes will identify updates that require a new game or have known save-compatibility concerns.

**When a new save is required, do not continue an existing save on that revision.**

When an update is expected to be save-safe, making a backup is still strongly recommended.

Unless there is the necessity for a hotfix, you are under no obligation to update the Mod List. Do not FOMO, wait until you want to start a new save before updating.
